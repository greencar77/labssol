# Mermaid Diagram Sample

This project contains a sample Mermaid diagram.

## Sample Diagram

```mermaid
graph TD
    A[Start] --> B{Is it working?}
    B -- Yes --> C[Great!]
    B -- No --> D[Keep trying]
    D --> B
```

## How to view
You can view this diagram in GitHub, GitLab, or any Markdown editor that supports Mermaid.
